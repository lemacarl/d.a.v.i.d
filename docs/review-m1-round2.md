- **Script fidelity:** no text changed. `git diff 380c13b..HEAD -- data` touches only `audio.json`, `balance.json`, `recurring-lines.json` (adds `continue` and `modes`, no script text altered) and `stages/ch1.json` (numbers, trigger names, removed duplicates). - **Blessings and modes cannot change a story outcome:** `StageBase.win()` still takes no modifier input; hit counts, `minAlive` and 90 s / 60 s durations are data and unaffected. Song of Courage frightens but never damages and a frightened boss stays hittable and still needs the data hit count; Staff changes only sheep placement; Watchful Eyes only delays a spawn by a visual warning and lengthens the bear windup (the spawn is delayed, not removed). Win paths unchanged, confirmed by `_outcome_*` tests. Song hold vs tap: the host still counts a released hold as a tap (so a hold throws a stone on release), and `on_action_hold()` is a no-op without the Blessing and in cutscenes.
- **Per-frame allocation:** none new. New per-frame work uses `Color`/`Vector2` values and pooled actors; `telegraph` reuses the predator pool (cap `maxPredators`), frighten sets tint on existing nodes, SFX use 4 fixed players, one music and one voice player. Remaining allocation: one `Polygon2D` + tween per Lamb OK tap (bounded by the 0.35 s cooldown; P-2 unchanged, N-3).
- **Unbounded node creation:** none found (glow, telegraph, frighten, audio players all pooled or fixed).
- **Signal leaks:** new connections are stage->host and stage->autoload callables (freed with the stage) and `LineQueue` (RefCounted owned by the host). `RunState.tired` connection from the host is the same pattern as before and is dropped when the host frees. No new leaks.
- **Back never quits mid-run:** `main.gd` is unchanged in round 2; `config/quit_on_go_back=false`, quit only from the title (round-1 verification stands; the retest confirms on device for `f878653`).
