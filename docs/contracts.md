# Contracts (Builder A)

Public API of autoloads, model, modifiers and `StageBase`. Types are GDScript. Autoloads have no `class_name` (use the autoload name).

## StageBase (`stages/stage-base.gd`, `class_name StageBase extends Node`)
Signals: `stage_started`, `stage_won`, `stage_failed(reason: StringName)`, `hit_taken(amount: int)`, `sheep_saved`, `stone_thrown`, `follower_added(count: int)` (count = number added, not total), `line_requested(speaker: StringName, text: String, reference: String, line_id: StringName)` (line_id = data line id, empty for a verse caption; a speaker `caption` line is the verse caption of the line requested just before it), `gold_light_requested(text: String, reference: String, seconds: float)` (seconds from the data beat, 0 = `balance.feel.goldLightHoldSec`), `sfx_requested(cue: StringName)` (host plays it through `Audio`; stages never call `Audio`), `stone_collected` (host: `RunState.add_stones(1)`), `stone_spent` (host: `RunState.spend_stone()`), `counter_changed(kind: StringName, value: int)` (HUD counters `&"loaves"` and `&"time"`; value < 0 hides; the host forwards to `Hud.set_counter`). Host hooks: `wait_for_lines: bool` (the host sets it true before `begin()`; a stage may then hold timed phases), `on_action_press()` (every non-Lamb OK press; the tap follows on release), `on_lines_drained()` (the host line queue, `LineQueue.drained`, ran dry; the host also calls it right after `begin()` when nothing was queued). Helpers `report_stone_collected()`, `report_stone_spent()`, `report_counter(kind, value)`.
Fields: `def: StageDef`, `run: RunModel`, `mods: ModifierStack`.
Methods: `setup(def, run, mods)`, `begin()` (calls hook `_on_begin()` then emits `stage_started`), `on_action_tap()`, `on_action_hold()` (override), `get_modifier(key, base: float) -> float`, `get_flag(key, base: bool) -> bool`, `get_feature(key, default)`, `timer_enabled()`, `enemies_enabled()`, `stones_refill()`, `win()` (emits once), `fail(reason) -> bool` (false if the mode vetoes; stage must keep running), `is_finished()`, emit helpers `take_hit(amount=1)`, `report_sheep_saved()`, `report_stone_thrown()`, `add_followers(n)`, `request_line(speaker, text, reference, line_id)`, `request_gold_light(text, reference, seconds)`, `request_sfx(cue)`, `play_event(trigger) -> Array` (emits lines for narration/dialogue/caption/gold-light beats via LineBook; returns the other beats for the stage to handle). A stage never calls RunState, never changes screens. Time-limit stages must check `timer_enabled()`; enemy spawners `enemies_enabled()`.

## StageDef (`model/stage-def.gd`, RefCounted)
Fields: `id, script_ref, chapter, title, type, params, win, lose: Array, on_lose, events, references, blessing_after: bool, next_id` (empty = chapter ends), `mode`, `raw`. Mode overrides already merged (params deep-merge; win, lose, onLose replace; events replace per trigger).
Static: `from_dict(d, mode)`, `load_chapter(n, mode) -> Array[StageDef]`, `deep_merge`.
Accessors: `param(path, default)` (dotted path ok, e.g. `"phase2.glowSec"`; call in setup, not per frame), `param_int/float/bool/string(path, default)`, `param_dict(path)`, `param_array(path)`, `win_kind() -> StringName`, `beats(trigger) -> Array`, `cutscene_beats() -> Array` (from data/cutscenes via `params.cutsceneId`), `story_line_ids()`, `lose_for(reason)`, `has_lose(reason)`, `on_lose_for(reason)`.

## RunModel (`model/run-model.gd`)
`enum Mode { NORMAL, SHEPHERD, LAMB }`. Fields: `mode, chapter, stage_index, hearts, hearts_max, stones, followers, blessings: Array[StringName], cleared_stages, sword_unlocked, stats {sheep_saved, stones_thrown}, rng_seed`. Methods: `start_chapter(n, max_hearts)`, `reset_attempt()`, `to_dict()`, static `from_dict`, `mode_key(mode) -> String`, `mode_from_key(String)`.

## RunState (autoload `RunState`)
Signals: `hearts_changed(hearts, hearts_max)`, `stones_changed(stones)`, `followers_changed(followers)`, `blessing_added(id)`, `run_failed(message: String)` ("pool:{id}" or "line:{id}"; resolve with `LineBook.resolve`), `chapter_completed(chapter)`, `stage_changed(def: StageDef)`, plus `blessing_offered(options: Array)` (cards; answer with `add_blessing` or `skip_blessing`), `tired(seconds: float)`, `rested`.
State: `model: RunModel`, `mods: ModifierStack`, `current_stage: StageDef`, `stage_defs`, `chapter_data`, `awaiting_blessing`, `is_tired`.
API: `start_chapter(n, mode)` (emits counters, then `stage_changed` for stage 0), `advance()` (stage won: emits `blessing_offered` if the stage has blessingAfter and options exist, else `stage_changed` or `chapter_completed`), `add_blessing(id)`, `skip_blessing()`, `available_blessings()`, `offer_blessings()`, `fail_stage(reason) -> StringName` (`&"ignored"` | `&"restart-chapter"` | `&"restart-stage"` | `&"goto-stage"`; Shepherd and Lamb always ignored), `apply_hit(amount=1)` (Normal: zero hearts fails the stage when the stage has a `hearts-zero` lose entry, otherwise hearts stay at 1; Shepherd: emits `tired(3.0)`, host waits then calls `end_rest()`; Lamb: no damage), `end_rest()`, `heal(n)`, `restart_chapter()`, `restart_stage()` (pause menu), `set_mode(mode)` (then call `restart_stage()`), `set_stones/add_stones/spend_stone() -> bool/stones_refill_enabled()`, `set_followers/add_followers`, `record_sheep_saved()`, `record_stone_thrown()`, `unlock_sword()` (also automatic when stage `3-4-nob` is cleared), `end_run()` (quit to title: clears sword and Blessings), `set_chapter_data(n, chapter, stages)` and `set_seed(s)` for tests.
Reads `data/chapters/chN.json` and `data/stages/chN.json`; stage order follows the chapter `stages` list.

## ModifierStack (`model/modifier-stack.gd`)
`TUNABLE_KEYS` (13), `STORY_KEYS` (5), `EVENTS` (`stage-fail`, `timeout-fail`, `david-fall`, `enemy-spawn`). `apply(key, base: float) -> float`, `apply_bool(key, base: bool)`, `allows(event) -> bool` (story events always true), `feature(key, default)` (non-numeric Blessing data by data-schema key), `set_mode`, `add_blessing(card)`, `set_blessings(ids)`, `clear_blessings()`, `rejected_keys` (must stay empty). Booleans are 1.0/0.0. Blessing key mapping: stoneSpeedMult->stone-speed, followRadiusMult->follow-distance, walkSpeedMult->walk-speed, patrolNoticeTimeMult->notice-time (multiply); bossStunBonusSec->stun-time, heartsRestoreOnStageStart->heart-regen, startFoodAdd->food-start (add); other registry keys via `feature()`.

## Others
- `Modifier` (base), `ModeBase/ModeNormal/ModeShepherd/ModeLamb`, `BlessingModifier(card)`.
- `BalanceData` (static): `balance()`, `hearts_max()`, `invulnerable_sec()`, `harp_hold_sec()`, `mode_settings(key)`, `blessing_cards()`, `blessing_card(id)`, `offer_count()`, `lamb_completion_unlocks()`, `read_json(path)`, `as_dict(v)`.
- `LineBook` (static): `line(id) -> Dictionary`, `cutscene_beats(id) -> Array`, `pick(pool_id, rng)`, `resolve("pool:x"|"line:x", rng)`. Reads data only.
- `SaveModel`: `chapters_unlocked, mode: String, settings {music_volume, narration_volume, subtitle_scale}`; `is_unlocked(n)`, `unlock_after(completed, mode_key, lamb_unlocks)`, `to_dict()`, static `validate(v)`, `from_dict(d)`.
- `SaveData` (autoload): `model: SaveModel`, `load_save()`, `save() -> bool`, `is_unlocked(n)`, `unlock_after(n, mode_key)`, `set_mode(key)`, signal `saved`. Connects itself to `RunState.chapter_completed`.
- `Settings` (autoload): `music_volume, narration_volume, subtitle_scale`, `set_music_volume(v)`, `set_narration_volume(v)`, `set_narration_enabled(b)`, `narration_enabled()`, `set_subtitle_scale(v)` (floor 1.0), signal `changed`.
- `Audio` (autoload): buses Music, Narration, Sfx created at start (levels from `data/audio.json`: Music -10 dB, Sfx -6 dB); `MUSIC_MAIN`, `play_music(cue)` (no restart if already playing), `stop_music()`, `play_sfx(cue)`, `narrate(line_id)` (plays `audio/narration/<line-id>.ogg`, ducks the music, no-op if the file is absent), `stop_narration()`, `play_harp()`, `duck(on)`, `cue_paths(cue)`, `narration_path(line_id)`. Cues are looked up by id in `data/audio.json` (`paths` = one or several variants, `bus`, `loop`); `.ogg` and `.mp3` both load. Unknown cue or missing file = silent no-op.
- `LineQueue` (`ui/line-queue.gd`): `request(speaker, text, reference, line_id)`, signals `line_started(...)`, `caption_started(text, reference, hold)` (a caption is shown with its own line's turn), `narration_started(line_id)`.
- `BalanceData.feel(key) -> float`: a number from `balance.json` `feel`. `UiText.modes()` (ids and names from `recurring-lines.json` `screens.modes`), `UiText.continue_label()`.
- Blessing effects read by the stages: `follow-distance` (Shepherd's Staff: flock wander and drift scale by it and the flock's resting spot slides toward David), `harpFrightenEnabled/RadiusPx/Sec` (Song of Courage: `on_action_hold()` frightens predators within the radius, no damage), `enemyTelegraphSec` (Watchful Eyes: predators glow that long before appearing; the bear's warning lasts that much longer).

## Chapter 2 stages (Builder F)
- `StageDelivery` (`type delivery`, 2.2): params `timeLimitSec, loavesStart, loavesFloor, lossPerDrop, halfwayAt, walkSpeed, hazards[{kind,speed,count}]` (kinds `cart`, `goat`, `rolling-rock`; capped at `MAX_HAZARDS` 16, nodes reused), `win.minLoaves`. Hazards are not enemies and stay in Lamb. A bump costs `lossPerDrop`, knocks David back (`feel.bumpKnockbackPx`) and gives `hearts.invulnerableSec` of invulnerability; hearts are untouched. `loaves-zero` and `timeout` go through `fail()`; where the mode vetoes, loaves are held at `loavesFloor` and the timer is not armed (`timer_enabled()`). Events `halfway` (progress >= `halfwayAt`) and `win`. Emits `counter_changed` `loaves` and `time`.
- `StageStealth` (`type stealth`, 2.5 collect variant): params `walkSpeed, sightSec, onSeen, stoneSpots.count, scouts{count,speed,sightRangePx}, hidingSpots.count`. A scout sees David inside `sightRangePx` unless he stands just below a rock (`is_hidden()`); `sightSec` (through `notice-time`) of being seen triggers `onSeen` (`pushback` = back to the near bank; `reset-position` / `return-to-path-start` = start). Never a failure, no stone lost. Scouts speed and `sightSec` come from the mode block in data (Shepherd 0.6x / 2x are written there; the code does not apply `enemy-speed` again); Lamb `scouts.count 0`, and `enemies_enabled()` false also removes them. Per stone: `stone_collected` + event `each-stone`; all stones: `stones-complete`. Win = David enters the exit; carry is RunModel.stones.
- `StageGoliath` (`type boss`, `variant weak-point`, 2.6; the host maps it to `stage-goliath.tscn` through `StageHost._scene_key`): phase 1 spears down `phase1.spearLanes` horizontal lanes (`spearSpeed`, `spearIntervalSec`, one spear per lane per round, warning `feel.spearTelegraphSec` + Watchful Eyes), shield-bearer bounces stones (free); phase 2 laughs `phase2.laughSec`, forehead glows for the last `phase2.glowSec`. OK in the glow always wins (no modifier is read): a press that began in the glow (`on_action_press`) is a hit even when released after the glow closed, and a glow tap bypasses the 0.35 s throw cooldown; a press that becomes the 2 s harp hold is never a throw or miss. While `wait_for_lines` and the host has not drained the `enter` lines (and the first laugh), the stage runs no phase timer, spear or tap. OK in the laugh before the glow is a miss: one stone (`stone_spent`) unless `stones.refillOnMiss` or the mode refills, then nothing is spent. `fail(&"stones-out")` at 0 stones (also on the first frame with no stones). Lamb (`spearLanes 0`, enemies off): laughs from the start. Stones the stage starts with = `RunModel.stones`.
- `StageCutscene` extras: beat types `sfx` (cue to `sfx_requested`; cues `slow-motion` and `screen-shake` also start the effect), `shake {amount, seconds}`, `slow-motion {scale, seconds}`, timed cut-away `visual` cues (`*stone-flies*`, `*faces*`, hold `feel.cutawaySec`), `end-card`. Signal `visual_requested(cue)`. Visual cues naming a body (`StageUtil.is_body_cue`) are refused. Slow motion eases `Engine.time_scale`; `restore_time_scale()` runs on finish, setup, pause (`NOTIFICATION_PAUSED`), leaving the tree and deletion, and `StageHost.clear_stage()` sets 1.0. Shake is clamped to `feel.shakeMaxPx`.
- RunState stones: `win.carry` containing `stones` lets the stones travel into the next stage; any other stage end clears them. Reset at chapter start and by any restart that lands before the carrying stage; a pause-menu restart restores the stones carried in (`_entry_stones`).
- RunState restarts: `fail_stage` with target `restart-stage` re-enters the same stage with the stones it was entered with. A restart that keeps Blessings drops those picked at or after the target stage's index (`RunModel.blessing_stage`, id to stage index at pick time), so a replayed stage offers and applies one pick. 2.6 `hearts-zero` has its own `onLose` (`restart-stage`, `pool:david-falls`); the scripted go-back line is only for `stones-out`.
- New `feel` keys: `stonePickupRadius, hideReach, hideHalfWidth, bumpKnockbackPx, spearTelegraphSec, spearHitRadius, slowMotionScale, slowMotionRampSec, slowMotionSec, cutawaySec, shakePx, shakeSec, shakeMaxPx`. New audio cues: `thud, bump, pickup, bounce`.
