# Credits and licences

## Engine
Built with the Godot Engine (https://godotengine.org), MIT licence. Godot is credited as a courtesy; the engine's own licence texts are bundled inside the exported game by Godot.

## Art and icons
All visual art in the game and the app icon, launcher icons, TV banner and splash are original placeholder work (flat shapes: a shepherd's crook and a star), drawn for this project (`icon.svg`, `tools/make-icons.py`). They are not derived from the Godot logo. Painterly 2D art is planned for Milestone 4.
